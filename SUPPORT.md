# Getting help

- **Something broken?** Open an issue in the repository it belongs to, using
  the bug template.
- **A question about how to use something?** Open an issue with the question
  template. If the answer belongs in the docs, we'll add it there too.
- **A security problem?** Follow the [security policy](SECURITY.md). Never use
  a public issue.
- **Anything else** (partnerships, press, licensing): [hello@dcyfr.ai](mailto:hello@dcyfr.ai).

Issues are triaged by a small team, so a reply can take a few days.
